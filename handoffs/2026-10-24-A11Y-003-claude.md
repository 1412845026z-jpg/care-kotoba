## 改了什么

| A11Y-CI-001 项 | 改动 |
| --- | --- |
| 1 Modal 没有可访问名称 | 共享 `Modal`（`components/ui.tsx`）打开时用第一个 h1–h3 作为 `aria-labelledby`（没有 id 时生成一个）。场景说明、设置、访问码、法人示例的弹窗都由此得到名称 |
| 2 手机筛选按钮没有名称 | `.filter-button` 加 `aria-label="レベルで絞り込む"` 和 `aria-expanded` |
| 3 品牌按钮名称与可见文字不一致 | 侧栏与顶栏的品牌按钮改为 `aria-label="Care Kotoba ホームへ"`（包含可见的 Care Kotoba） |
| 4 练习覆盖时重复的 landmark | 练习 / 反馈打开时，背后的侧栏、`.app-shell`、底部导航加 `inert` 和 `aria-hidden`。练习根元素是 `role="dialog"`、`aria-modal`，以场景名的 h1 命名（`practice-top-title` 的 strong 改为 h1，外观不变）；`.practice-layout` 改为 `<main>`；反馈根元素以 h1 命名。关闭练习后焦点回到打开前的元素，不在页面上时回到当前页的 h1（页面 h1 加了 `tabIndex={-1}`） |
| 5 标题跳级、两个无名 aside | 反馈页「次のひとことを、もっと自然に。」「フィードバック画面の表示例」h3 → h2；ことばノート「保存した表現」h3 → h2；侧栏 `aria-label="メニュー"`，右栏 `aria-label="今日の記録"`（外观不变） |
| 6 opacity 造成的对比度不足 | 注音 `rt` 不再半透明（opacity 1）；分类胶囊里的计数不再半透明 |
| MERGE-2：选完会話のタイプ后焦点丢失 | 选完后焦点回到「変える」按钮（`id="variant-toggle"`） |

**另外发现并修正的回退**：会话舞台（深梅色渐变）上的计时、「ゆっくり聞く／ヒント」、底部提示、桌面的对方标签只有约 2.5:1。原因是 DEAI-001 的颜色换算把中间调文字一律压暗，而舞台是深色背景；原来的可读性检查遇到渐变背景就跳过，所以没有发现。现在舞台上的文字改为浅色（7.9–11:1）。舞台字幕的注音最小 10px（原来 7px）。

**检查工具补强**（`verification/A11Y-001/audit.mjs`，Codex 的 CI 硬门会运行它）：
- 对比度计算乘上元素和祖先的 opacity（和 axe 一样）；
- 渐变背景不再跳过，按最差的色标计算（图片背景仍跳过）；
- 测量前等进场动画结束（无限循环的动画除外），避免测到半透明的弹窗。
- 负对照：补强后的检查在修正前的代码上报出舞台文字 3 处（2.46–2.5:1），修正后为 0。
