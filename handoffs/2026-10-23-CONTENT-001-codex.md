## 文件与内容

新增 `content/scenarios/schema.json` 和 12 个 `CK-*.json`，三项目标各四个：主动问清、尊重拒绝、报告确定性。
每个场景有版本、目标、已知/隐藏信息、揭示条件、三条对话分支、两个可接受表达、反例、反馈规则和迁移题。
全部标注「草稿，待介护经验者与日语教育者审稿」，fictional=true，approved=false。

新增 `evals/schema.json`、`samples.jsonl` 与评分说明。48 条虚构转写：每场景一条好例、常见错误、关键 ASR 不确定、可接受表达变式。
三个目标分别有 met / missed / uncertain / not_applicable 标签；非空证据逐字来自指定学员发话。
关键否定/数量/部位误听先确认，不把它当作清晰错误；不得引用参考答案或未揭示信息冒充学员原话。
尊重拒绝不要求问出理由；报告场景不要求补造诊断、原因、目击或整夜情况。

新增 Python 标准库数据校验器及三项保护测试；它只实现本 schema 使用的关键字子集，**不是完整 JSON Schema 认证**。
CI 增加这两个离线数据检查命令。没有新增 npm 依赖，没有修改 `prototype/lib/content.ts` 或任何冻结文件。
