# SSW-BASIC-APP-001｜基础课（特定技能介护，96 场景）接入 App（Claude，2026-10-24）

- 来源：SSW-CONTENT-001（Codex，PR #56）交给 Claude 的接续：「读取 catalog 接基础课程入口、逐字注音和现有练习/笔记」。用户方向：面向特定技能外国介护人员，简单实用。
- 分支：`claude/SSW-BASIC-APP-001`，基于 `claude/A11Y-003`（PR #57 未合并）。**PR 的 base 是 `claude/A11Y-003`**：先合并 #57，再合并本 PR（#57 合并后把 base 改为 main）。
- 没有改依赖、CI、部署配置、`content/`、`tools/ssw-basic/`；没有调用付费 API。基础课练习本身不访问任何 AI 或语音接口。

## 做了什么

- **生成器** `tools/ssw-basic-app/generate.mjs`（`--check` 可检查是否过期）：从 `content/ssw-basic/catalog.json` 生成 `prototype/lib/basic-course-data.ts`（约 180KB，进入「基礎」页或打开含基础课笔记的ことばノート时才按需加载）。
  - **逐字注音**：把内容方审过的整句读音（`kana`）和日语原文对齐，为每个汉字块写出 `{漢字|かんじ}`。对齐用回溯，列出所有可能的切分后选每个汉字约两个假名的那一种，避免「{昨日|き}の{夜|うのよる}」这类错误。384/384 行对齐；有多种切分的 4 行（S16、S37、S68、S91）都选对了，并写进单元测试。对不齐的行会改为显示整句假名（目前 0 行）。
  - 摘要只算 App 用到的字段，不含 catalog 版本号。所以 VOICE-EXPRESSION-001（PR #58）这类只加语气说明、不改台词的更新不会让生成文件过期（已用 #58 的 catalog 实测 `--check` 通过）。
- **App**：
  - 新增「基礎」页（底部导航第 2 个，桌面侧栏「基礎の声かけ」）：24 个主题，每个显示练习进度「n/4」；点主题看 4 个场景；点场景打开练习。
  - 练习：显示你的回答之前的几句（带注音，可「訳を表示」看中文）→「あなたの番です」→「答えを見る」→ 参考回答、「こんな言い方も」（替代说法）、中文要点（珊瑚色）、「ノートに保存」→ 后面的对话 →「言えた・練習済みにする」「次の場面」。
  - 「ゆっくり聞く」只用设备自带的日语语音（新增 `sayLocal`，不访问 `/api/speech`）。没有日语语音时提示，不改用其他语言的语音。原有的 `sayText` 在服务器朗读失败时也改用 `sayLocal`。
  - 首页新增「基礎の声かけ」卡片，显示练习过的场景数。
  - 练习记录存在 `localStorage` 的 `ck-basic`（场景 id → 日期），只存本机、不打分；「この端末の学習データを削除」会一起清空。
  - 从基础课保存的笔记显示「基礎 · 场景名」和「基礎で練習」按钮，可以回到该场景；「今日の復習」也显示基础课的场景名。
- **可读性检查**：`audit.mjs` 新增「基礎」列表和「答えを見る」后的练习两个画面。静态检查的组件列表加入 `review.tsx` 和 `basic-course.tsx`。
