# 固定转写评测草稿 0.2.0

草稿，待介护经验者与日语教育者审稿。全部为虚构转写，不含实际学员数据或音频。

`samples.jsonl` 包含84条固定样本：每场景保留原四类样本，再补一个细微错误（E5）、一个有前后修正的两轮样本（E6）、一个简单但正确的变式（E7）。原有48条加36条，另有12条配对反馈样本。场景内容从 `../content/scenarios/` 读取；每条样本固定场景版本及已揭示的隐藏信息。

## 标签与原话依据

- `met`：这条转写满足适用的语言目标。
- `missed`：清晰转写显示具体问题，有可引用的原话证据。
- `uncertain`：关键转写不足，应该先确认；不得猜出否定、部位、数量或缺词。
- `not_applicable`：此样本不用于该目标的评价，不放进该目标的通过率分母。

`feedback_evidence` 必须逐字来自指定的学员转写，不能引用参考答案或角色隐藏信息冒充原话。不可靠转写样本将证据留空，并明确期望先确认；空证据不表示学员错误。不同礼貌表达应按意图接受，不强求复杂敬语或参考句匹配。

## 后续模型迁移评测方法（本轮只写数据，不执行API）

1. 固定场景、样本与提示词版本，保存每次模型返回的标签、引用及下一步反馈。
2. 分别统计三个目标的标签一致率，排除 `not_applicable`；将 `uncertain` 单独报告，不能算成普通失败。
3. 对12个不可靠转写样本，统计是否先确认、是否捏造缺失词、是否误判学员错误。
4. 对12个表达变式，统计错误纠正率；对所有非空引用，检查逐字引用和发话ID。不要只报一个总分掩盖这两类错误。
5. 对明确错误样本核对是否抓住实际问题，同时报告漏检和误报。预期标签仍需两类专业审稿；不能把本草稿当成已经校准的金标准。

录音缺席时不评发音。语音延迟、断线恢复、实际麦克风与教学效果均不在这些数据的验收范围。

## 本地检查

`python3 evals/validate.py`

检查脚本只用Python标准库，覆盖本包使用的schema基础约束，以及跨文件ID/版本、三目标覆盖、分支隐藏信息引用、原话逐字证据、不可靠转写的拒绝硬评分。它不是通用JSON Schema实现，不能将它的结果描述为第三方完整规范认证。

CONTENT-004 不改变字段结构。E6 的 `learner_transcript[]` 按顺序记录学员L1、L2；没有录音或中间NPC台词，不假设二者存在。期望反馈同时定位L1缺项并肯定L2的最新修正；不能用旧错否定后来的修正。不同礼貌程度仍应按意思接受。
