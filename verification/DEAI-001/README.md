taste-skill 和 impeccable 剩下的项目，以及没有改的理由：

- **注音 `rt` 小于 11px**（两个工具都报）：注音是汉字上方的读音标注，按日文排版习惯约为正文的一半；现在是 `max(.55em, 10px)`。做到 11px 需要正文约 20px，不现实。注音可以在设置中关闭。可读性检查对正文的 12px 下限不包括 `rt`。
- **米色背景**（cream / palette-cream）：这是用户选定的概念图方向（暖白纸色）。impeccable 的规则也写明「brief wins」。
- **首页标题 36px**（app-title-size，桌面）：概念图把大号明朝体标题作为首页的邀请；手机上是 28px。
- **场景卡片里 44px 空白**（panel-void，1440px）：三张卡片等高，时长 · 等级 · 箭头对齐在卡片底部，便于横向比较。
- **首屏列高**（first-viewport-column-overflow，1280px）：桌面是主栏加右栏的应用布局，主栏比右栏长是正常的。

impeccable `detect` 的文件扫描（`.tsx` / `.css`）对新旧文件都返回 0 项，包括故意用旧文件做的对照，所以文件模式对这个项目不起作用，以上数字都来自 URL 扫描（本机 Chromium 加 `--no-sandbox` 包装，访问离线 harness）。
