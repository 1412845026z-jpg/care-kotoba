手机请用单文件版

打开或下载 mobile-listen.html，所有音频已经内嵌。当前 index.html 需与原 audio/ 文件夹放在一起。

如果聊天或文件 App 只显示源码/预览而没有播放器，请下载后用浏览器打开。iPhone 的文件预览和浏览器打开行为因系统而异；若仍不支持，回到 README 直接点 MP3，不需要注册、安装 App 或部署网站。GitHub 的 HTML 文件页本身不会渲染此清单。

3. 建议优先比较的两个组合

  1. 组合 A：麒ヶ島宗麟（年长男性利用者）＋雀松朱司（男性职员）。先检验年长感与职员的清楚、亲切是否同时成立。两者署名分别为 VOICEVOX:麒ヶ島宗麟、VOICEVOX:雀松朱司。
  2. 组合 B：麒ヶ島宗麟（年长男性利用者）＋jf_alpha（女性职员）。优先比较两种角色能否更容易区分；jf_alpha 的日语自然度需要重点听。保留麒ヶ島署名及 Kokoro 来源/Apache 许可。

以上只是待你试听的候选。先不要批量生成或接入 App。这里的五句是学员参考句，年长音色读这些句子仅为比较声音，不代表利用者台词已通过专业审稿。

4. 听完发回这些就够了

每个候选至少听第 2、3、5 句；尤其关注「理解」「合っています」「転倒」「瞬間」，以及长句的停顿和句尾。音素检查未见上述词明显拼读错误，但不能证明实际重音和听感。
