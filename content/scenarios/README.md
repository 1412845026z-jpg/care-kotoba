# 场景规格草稿 0.1.0

草稿，待介护经验者与日语教育者审稿。全部为虚构案例，尚未获专业审稿批准。

12个场景按三种语言能力各4个组织：C为主动问清，R为尊重拒绝，P为区分已确认与未确认的报告。每个JSON包含目标、学员已知信息、隐藏信息、角色分支、示例与反例、反馈规则、迁移题和版本。

`schema.json` 使用 JSON Schema 2020-12 的基础字段描述结构。角色引擎只在满足揭示条件后向学员透露隐藏信息；评估不得要求学员预先知道它。明确拒绝可以礼貌接受并结束，不强制问出理由。

语言例子不是临床处置指导；带有痛感、进食或发现状态的场景仅练习如何准确报告，不给诊断、饮食、搬运或治疗建议。实务依所属设施手顺和负责人指示。

审稿需分别记录介护经验者对真实性与边界的意见，以及日语教育者对自然度、理解负担和反馈依据的意见；分歧不取平均掩盖。更改场景或预期标签时增加版本并保留变更说明。

从仓库根运行 `python3 evals/validate.py` 检查结构、引用、覆盖及原话证据。这是数据校验，不证明教学效果，也没有调用模型。
