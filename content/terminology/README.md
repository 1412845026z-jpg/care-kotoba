草稿，待介护经验者与日语教育者审稿。此目录尚未接入应用；不修改 `prototype/lib/content.ts`。

`terms.json` 包含34条：30个常用词的词形、读音和页码与厚生劳动省网站所载《外国人のための介護福祉専門用語集》中国语版索引核对，另4个沟通词条由本项目编写。中文、英文的学习释义、虚构例句、场景关联和反馈规则均为Care Kotoba本轮原创草稿；没有复制教材定义、翻译段落、插图、版面或标志，也没有把整份PDF加入仓库。

`scenario-map.json` 对应已有12个场景。`core_term_ids` 用于该场景本身；`transfer_term_ids` 只是换词迁移练习的候选，不改变原场景的已知或隐藏信息。每条词语可关联多个场景。不能为了用上一个术语而向学员泄露隐藏信息或添加照护任务。

## 教学边界

- `主観的事実 / 客観的事実` 描述信息的性质；`已确认 / 未确认` 描述一个具体断言的核实状态。这是两个维度，不能做成互斥的两类标签。
- 例：“中村さんは『左のひざが痛い』と話しています。”可以确认本人说过这句话；疼痛原因仍可未确认。主观陈述不等于不可信，客观观察也不自动证明原因。
- “发现坐在地上”与“看见跌倒过程”分别记录。一次午餐的观察不自动成为近几天的趋势。传闻可准确标明来源，不能改写成自己的观察。
- 尊重拒绝可以是成功结局，不要求最终入浴、进食、换衣或参加活动；没有说出的拒绝理由不自行补造。
- 词义与读音卡不证明发音正确、具备介护能力或可执行某种操作。移乗、清拭等卡不含具体操作、饮水量、诊断或个体照护方案。

## 来源与权利状态

来源清单与2026-10-24 JST的核对方法见 `sources.json`；下载SHA-256与索引位置见 `verification/CONTENT-002/`。`pdf_entry_page` 是PDF从1开始的页数，`printed_entry_page` 是书页上印的页码，两者不要混用。

厚生劳动省网站的通用条款指向PDL1.0，要求出处与加工声明，并保留第三方权利例外。教材PDF的出版者为日本介護福祉士会；中国语用语集PDF第225页有其学习网站的版权广告，第227页为协会出版信息。这个发现既不能证明整本PDF完全禁止复用，也不能证明教材全文、译文和插图已获PDL1.0许可。教材正文、译文和图像的商业再利用许可本轮仍记为**未确认**。

因此，本目录目前只记录常用词和页码事实，并写本项目自己的教学说明，不将整本PDF标为“PDL已清权”。若后续复制教材段落或图像，应先核实对应权利；当前数据不依赖复制这些内容。
