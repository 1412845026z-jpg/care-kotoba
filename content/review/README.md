# 离线内容审稿台（CONTENT-003）

用浏览器直接打开 `index.html`。页面已嵌入12场景、34术语和60评测草稿，无需服务器、npm、账号、密钥或AI调用；没有外部字体或脚本请求。字体使用设备已有的中日文字体。此页用于审稿，不是学员应用入口。

- 按场景搜索并查看目标、开场、已知信息、隐藏信息、分支、表达例、反例和迁移题。隐藏信息默认折叠，仅供审稿，未揭示前不作为学员答案前提。
- 相关术语分核心词与迁移候选，显示读音、原创学习释义、反馈规则和参考页码。
- 评测片段展示固定发话与反馈候选；评分草稿默认折叠。不要把配对ID或评分答案送给被测模型。
- 每个场景可写意见、标记建议修改或保留草稿。本机存储失败时仍可导出JSON。导出包含资料来源指纹与逐文件SHA-256、场景ID和意见，`formal_approval=false`；不会改动源JSON或把内容标成已专业审批。
- 全部案例虚构。请只写措辞、情境和证据方面的审阅意见，不放入真实利用者资料。

修改源数据或模板后，从仓库根运行：

```sh
python3 content/review/build.py
python3 content/review/build.py --check
```

第二条只检查生成页与16份输入文件是否一致，已加入常规CI。它不运行浏览器，也不验证教学质量。`template.html`是维护模板，正式打开的是生成后的`index.html`。

本轮浏览器验证命令与结果见 `verification/CONTENT-003/browser-check.mjs`、`browser-results.json`。覆盖搜索、切换场景、注音、评分草稿、本机意见、JSON导出、键盘、损坏记录和390px宽度。无真实AI、移动真机或专业审稿结论。
