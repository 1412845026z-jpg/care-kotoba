# 特定技能外国介护人员・基础工作日语

版本0.2.0，2026-10-24。虚构、AI辅助编写，待介护经验者与日语教师审稿。首批24类×4＝96个微场景，提供一个沟通目标、4轮分角色短对话、假名读法、中文意思和两条可接受替代表达。它是基础覆盖首版，不代表穷尽所有介护工作，也不是考试认证或独立上岗能力判断。

## 直接使用

打开 `index.html`，选择主题或搜索词句；逐句看日语、假名与中文，隐藏参考答案后练下一句，再展开对照。页面不用账号、后端或付费API。

「端末朗读」调用浏览器/系统的日语声音，可能需要联网，也可能没有可用日语声音；这是临时试听，不能当作已生成的MP3。打开「语气提示」可看每句表达方向，但系统朗读不保证表现这些情感。源数据的汉字读音是审稿辅助，不是已完成逐字ruby注音；App里原有注音能力不因此被修改。

## 资料与音频

- `scenes-01-32.json`、`scenes-33-64.json`、`scenes-65-96.json`：可编辑正文。
- `sources.json`：官方资料与实际查阅范围。
- `catalog.json`：合并的可接入课程数据。
- `audio-plan.json`：逐句和替代表达待合成清单；同角色同文字同表达风格共用资产，并保留多个场景用法。553条基础文本考虑语气后当前仍为553条；不为凑数量增加录音。不同角色可以选择不同声音，因此暂不跨角色合并。
- `speech-delivery.json`：19种自然表达方向；`delivery-*.json` 为384轮台词及192条替代表达的逐句选择。情感根据语义变化，不由年龄或性别决定；同句需不同情绪时分开生成。
- `voice-profiles.json`：8档虚构声音身份、原16条身份试音稿及同一声线跨情绪的对照试音要求；均尚未合成和听验。
- `coverage.md`：当前主题覆盖、数量和后续补核范围。
- `qa-review.md`：独立第二轮AI编辑检查，不冒称真人专业签核。

常用句在不同场景重复是正常的。教材用于核对工作领域、常用词与表达用途，正文由项目重新组织为自己的情境和对话；本包不包含原书录音、插图、试题集或页面。具体查阅范围和资料链接见 `sources.json`。

## 难度和边界

以简单です／ます、一句话一件事为主；承认多种自然说法，不要求统一背诵或复杂敬语。中文是当前辅助语言版本，不代表目标用户只限中文母语者；后续可增加原创译文。

疾病、用药、测量、搬运等情境只练说明、询问、转述和求助，不教阈值、药量、诊断或介助手技；真实动作依所属机构安排与负责人指导。基础课程不是用语言正确来判定临床处置正确。所有人名与情境均为虚构。

先不强行替换已有48场景或12核心草稿，也不修改它们的schema；正式App入口/逐字注音/学习记录/声音映射由接入任务另行完成。最终音色未选、真人专业审稿和实际可听验收仍待完成；现有30段比较样本保留。

## 重建与检查

仓库根运行 `python3 tools/ssw-basic/build.py`，然后 `python3 tools/ssw-basic/build.py --check`。这些只在本机生成静态资料，不调用模型或外部服务。
