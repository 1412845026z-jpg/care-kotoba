# 产品背景与确定要求

## 用户问题

目标用户是在日本养老介护现场工作的外国职员，首批优先验证就职初期或现场会话吃力的人。产品帮助其问清指令、尊重利用者的拒绝、清楚报告，并在具体回合复练。不要按国籍或JLPT等级直接推定工作能力。

学习者在手机上练习；企业教育担当者在电脑网页上分配任务、查看约定的数据和安排下一步辅导。购买者可能是个人，也可能是设施长、法人培训负责人或相关培训机构。

## 用户明确要求

1. 正式上架应用商店，而不只交付网页或PWA。
2. 个人与企业使用相同学习功能；企业享批量优惠，额外增加管理能力。
3. 场景应丰富、接近实际行动和沟通，具有自然分支、实时AI语音及个别指导。
4. UI现代、专业；重视手机语音交互、反馈和复练，而不止聊天窗口。
5. 这是长期项目，工程、成本和交接必须支持持续迭代。不能把数次对话或一次原型构建当成项目完成。
6. 方案需包含视觉假想、功能页面、交互、可行性及销售路径；已有25页方案与交互设计可继承。
7. 用户关心开发期OpenAI费用，要求将它与ChatGPT订阅、上线后的学员训练成本及其他费用分开。
8. 最近要求先查成熟免费开源代码再考虑定制；本包附初筛结果。

## 建议保留的产品区别

- 从实际沟通难点出发：确认含糊指令、接住拒绝、说明已知和未确认事实。
- 场景包含已知/隐藏信息和教学目标，回应有分支。
- 反馈引用学员原话，给一个清楚的下一步，并对薄弱回合复练。
- 使用留出的变式题检查迁移，而非只背参考句。
- 企业端帮助担当者选择下一次辅导，不把练习音频全面变成员工监控。

上述区别是待验证的产品主张，不是已证实的教学效果或竞争优势。通用AI、HAi-J、免费教材和相邻产品已有相关能力，不能宣传市场空白。

## 内容与视觉

现有48个虚构场景、8类、144个参考表达和4个会话变式，均为草稿。第一批应深审12个场景，再扩大。

目标视觉采用柔和纸白、紫色和薄荷绿；学习入口、场景简报、暗色语音页面、引用原话的反馈、复练与企业周辅导视图。具体以PDF和可编辑HTML为参照；允许根据真机可用性调整。

首版使用虚构案例，不上传真实利用者介护记录。它是语言训练产品，不承担临床建议、介护能力认证或独立上岗认定。
