# 介护场景的角色声线与说话方式

2026-10-24用户要求：年长男女利用者、年轻男女职员、较年长男女职员及领导的声音和语言风格尽量可区分；优先AI生成自己的自然角色声，避免搬网上录音。角色定义和16条首轮试听文本已实际写入 `content/ssw-basic/voice-profiles.json`，目前尚未合成或听过。

## 两个独立维度

| 维度 | 如何使用 |
| --- | --- |
| 声线/虚构人物 | 8档：年长女/男利用者、年轻女/男职员、较年长女/男职员、女/男带班。每档有年龄印象、性别呈现、原创描述与试听句。音高、气息、共鸣、节奏共同形成辨识度，不只变调。 |
| 语言与表达方式 | 本人说希望、职员说明和征询、同事确认、领导清楚分步支持。领导不是靠凶或大声，年长利用者不统一颤抖、虚弱或幼儿化；具体情绪跟当前情境走。 |

年轻职员与年长职员都可用基础的です／ます。声音角色区分不要求把学员句子改复杂，不把说话人年龄和语言能力混为一谈。老人同样有清楚表达、拒绝和提要求的权利。

## 可行的生成路径

- **描述生成虚构新声线**：Qwen3-TTS VoiceDesign官方支持日语及自然语言声线设计。为了多句仍像同一个人，先生成并保存项目自己的候选参考音，再用官方Base复用流程维持身份；同一个描述每次重抽不保证一致。版本固定模型revision、描述、种子、参考音哈希和说话风格。
- **已安装插件的候选**：Higgsfield目录列Qwen Audio 3.0 TTS Flash，提供日语language=ja及表达instruction；当前可核实接口为预设/参考声音加风格控制，不等同该插件已提供VoiceDesign。列出的ElevenLabs对话模型也需另验日语和具体声线。没有因为插件安装就声称账号、音色或商业许可已验收。
- **当前费用预检**：用一条原创日语短句，在Higgsfield Qwen模型调用get_cost，返回0.01平台credits；明确No job submitted。仅是该短文本的预报价，不是日元价格、16段总价、声线适配证明或已经生成的录音。没有使用任何生成credits、充值或新订阅。
- **免费本机方案的现实边界**：当前可见约9.7GiB内存、9逻辑CPU、无可见NVIDIA设备，尚无torch/transformers/qwen_tts。官方有CPU路径，但未在此实测速度/内存；VoiceDesign仓库约4.52GB，稳定复用还需Base，不能保证当前机器立刻可完成全部合成。尚未下载模型或配置密钥。

完整官方资料与已核对边界见 `research/SSW_VOICE_OPTIONS_2026-10-24.md`。模型开源许可与服务输出商用条件分别确认，生成文件不是自动解除所有使用条件；不复制真人声纹作为本轮制作要求。

## 首轮试听与复用

每档两条：一条相同中性句、一条角色常见句，共16条候选；先比听感与身份辨识再全量。检查标准日语读音、长音/促音/数字、句尾自然度、年龄印象、角色区分、跨句一致、正常与慢速清晰度。听者未确认前，只能记录技术解码/非静音，不标“自然老人声通过”。

完整课程的audio-plan是按基础角色与文字去重的文本资产，不是最终录音数量。正式录音缓存键还须包含voice_profile、delivery_style、速度和模型配置版本；同句同声线同风格复用，不同角色声音不能用同一个MP3冒充。不要把553个文本资产机械乘8全部重录：每个场景只选择需要的虚构人物。

全量生成仍需最终声音选择、文本审稿、实际合成和可听验收。当前独立课程页的端末朗读使用系统现有日语声音，未实现这8个角色，不能作为多角色效果展示。之前30段仍只是音色比较样本。
