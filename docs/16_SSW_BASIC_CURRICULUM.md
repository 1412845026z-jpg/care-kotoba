# 特定技能介护基础日语课程・首批交付

用户2026-10-24明确：30段五句多音色样本不是课程规模；参考面向外国人的免费介护教材，了解实际工作有哪些情境、通常会说什么，再整理自己的场景。常用句跨情境复用很正常，不为了差异改得不自然。

## 内容组织

基础单元一景一任务，先给足词语和简单4轮对话，再让学员练其中职员的一句。尊重成人、允许拒绝和求助，基本です／ます即可。问清／拒绝／报告是跨场景技能；现有较复杂核心角色分支保留为进阶，不把其认知负担放在基础课开头。

首批24类96个微场景不是内容上限，也不声称几乎所有工作已经完成。主题包括见面入室、听不懂时求重说、确认指示、起居、穿衣、食前、饮食饮水、口腔整容、排泄、入浴、移动、环境、活动、不安、短报告、同事求助、手卫生、洗濯寝具、测量前沟通、药相关联络、通院康复外出、来客家人、防灾训练和身边用品。

## 教材实际使用

以厚劳省公开的日本介护福祉士会《介護の日本語》基础版目录和前言作为主题核对起点；特定技能改订2版发布页用于核对目标人群与现行资料入口。其他超出已实际核对教材目录的工作情境明确记为项目原创补充，不能伪造页码或官方背书。来源和限制见 `content/ssw-basic/sources.json`。

查阅了基础教材的前言和目录，不把它说成通读全部现行教材。当前20MB特定技能日文书在检索工具受体积限制，尚未逐页看完；后续可按具体缺项继续查阅，不阻碍先完成常见基础对话。

## 文件与接入

`content/ssw-basic/index.html` 为可直接打开的独立审稿／练习页；三份scenes JSON合并为catalog；audio-plan列明后续需要哪些录音，按角色与文字去重，避免同句在多个单元重复生成。页面的系统日语朗读不是MP3生成，也没有接入OpenAI或付费接口。

当前App代码归Claude负责，本次不改prototype/app、components、lib、tests，不改旧核心场景和生成schema。给Claude的下一步是读取catalog，通过新的基础课程入口呈现这些完整对话，沿用可开关注音、中文帮助和现有练习／笔记能力；接入必须明确基础课程、旧48场景与核心草稿的不同状态，不把新增文件当成界面已上线。

## 图片和后续声音

每个场景先记录image_brief_zh；选门口询问、衣物选择、物品位置、用餐/日常环境等可直观帮助理解的画面再生成插图。文字已经足够清楚的场景无需为凑数量配图，医疗或介助手技不靠生成图充当操作指导。本轮图片简报不代表已经生成图片。

全量正式音色仍待选择与文本审阅；原30段属于5句×5声音及5段比较。新课程的句子库与待合成资产数由生成器统计，不能把同一内容不同声音的数量说成新的情境数。先完成词句与覆盖，再统一生成和可听验收，减少返工。
